# 룬 타이머

<p align="center">
  <img src="./rune_timer_diamond_icon.png" width="96" alt="룬 타이머 아이콘">
</p>

룬 타이머는 메이플스토리 플레이 중 룬 등장 상태와 사용자 지정 타이머를 확인할 수 있도록 만든 Windows용 로컬 PiP 알림 도구입니다. 사냥 화면 위에 작은 보조 창을 띄워 룬 감지 상태, 룬 게이지, 커스텀 타이머를 한눈에 확인할 수 있습니다.

앱은 사용자가 지정한 미니맵 화면 영역을 PC 내부에서만 분석하며, 룬 아이콘이 표시될 때 알림음을 재생합니다. 게임 클라이언트의 파일, 메모리, 패킷, 입력 장치에는 접근하지 않으며, 별도의 인터넷 연결 없이 동작합니다.

브라우저 기반 타이머 사용이 부담스러운 저사양 PC, 부트캠프 Windows, 장시간 사냥 환경을 고려해 가볍게 실행되는 독립형 앱으로 설계했습니다. 화면 캡처 기반 감지가 부담스러운 경우에는 수동 모드를 사용해 순수 타이머 기능만 사용할 수 있습니다.

## 사용 전 확인해주세요

> **본인 책임하에 사용하는 비공식 보조 도구입니다.**
> 룬 타이머는 사용자가 지정한 화면 영역을 PC 안에서만 분석하는 보조 도구이며,
> 게임 클라이언트나 입력 장치에는 접근하지 않습니다.

### 비공식 보조 도구

룬 타이머는 메이플스토리 공식 서비스가 아니며, 넥슨 또는 게임 운영사의
공식 허가를 받은 도구가 아닙니다.

### 화면 캡처 기반 분석

사용자가 직접 지정한 미니맵 영역만 이 PC 안에서 분석합니다.
게임 클라이언트 파일, 메모리, 패킷, 키보드/마우스 입력에는 접근하지 않으며,
어떤 데이터도 외부로 전송하지 않습니다.
인터넷 연결 자체가 필요 없는 프로그램입니다.

### 수동 모드

화면 캡처가 부담스러운 경우, 캡처 없이 순수 타이머로만 작동하는
수동 모드를 설정에서 켤 수 있습니다.

### 사용자 책임

이 프로그램 사용으로 발생할 수 있는 계정, 게임 이용, 기타 문제의 책임은
사용자 본인에게 있습니다.

**위 내용을 확인했으며, 사용에 따른 책임이 본인에게 있음을 이해했습니다.**

## 주요 기능

- 미니맵 룬 아이콘 감지 알림
- 룬이 사라지면 알림음 자동 종료
- 커스텀 타이머 알림
- 타이머 일시정지/재개
- 10분/15분 룬 게이지 표시
- 극최소화 위젯 모드
- 설정 탭에서 알림음, TTS, 볼륨, 룬 게이지 기준 변경
- 수동 모드

## 수동 모드

수동 모드는 화면 캡처 자체가 부담스럽거나 불안한 사용자를 위한 완전 분리형 안전모드입니다.

- 수동 모드 OFF: 기본 모드입니다. 미니맵 캡처 기반으로 룬을 감지합니다.
- 수동 모드 ON: 캡처 스레드와 dxcam 캡처 객체를 사용하지 않고 순수 타이머로 동작합니다.
- 룬 게이지가 끝까지 차면 `룬이 등장예정입니다` 알림이 최대 3회 재생됩니다.
- 실제로 룬을 처리한 뒤 홈 화면 룬 아이콘 또는 최소화 위젯 룬 아이콘을 누르면 룬 게이지가 다시 시작됩니다.

## 사용 방법

1. 앱을 실행합니다.
2. 캡처 아이콘을 눌러 메이플스토리 미니맵 영역을 지정합니다.
3. 룬이 등장하면 알림음이 울리고, 앱의 룬 아이콘과 보라색 게이지가 활성화됩니다.
4. 창모드와 전체화면을 전환했거나 미니맵 위치를 바꾼 경우, 캡처 영역을 다시 지정합니다.
5. 캡처 없이 쓰고 싶다면 설정 탭에서 수동 모드를 켭니다.

## 주의사항

- 이 앱은 메이플스토리 클라이언트를 조작하지 않습니다.
- 키보드 입력, 마우스 입력, 자동 사냥, 스킬 사용, 방향키 전환 기능이 없습니다.
- 클라이언트 변조, 패킷 조작, 메모리 접근, 플러그인, 게임 API 사용이 없습니다.
- 기본 모드에서는 사용자가 지정한 화면 영역만 로컬에서 캡처합니다.
- 수동 모드에서는 화면 캡처도 하지 않습니다.
- 이미 거짓말탐지기가 자주 오는 계정 또는 제재 리스크가 민감한 계정에는 사용을 권장하지 않습니다.
- 미니맵 위치는 가능하면 기본 위치에 두는 것을 권장합니다.
- 창모드와 전체화면을 전환하면 미니맵 좌표가 달라질 수 있으므로 캡처 영역을 다시 지정해야 합니다.
- 운영정책의 최종 해석과 사용 책임은 사용자 본인에게 있습니다.

