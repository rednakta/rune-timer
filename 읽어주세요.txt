================================================================
 룬 타이머 (Rune Timer)
 Windows용 로컬 PiP 룬 알림 및 커스텀 타이머 도구
 버전 v1.1.1
================================================================


[ 이 앱은 무엇인가요 ]

화면에 보이는 미니맵의 룬 아이콘을 감지해서 알림음을 내는 보조 알림
앱입니다. 룬 게이지와 사용자 지정 타이머를 사냥 화면 위 작은 창으로
확인할 수 있습니다.

첫 실행 시 이용 안내와 사용자 책임 고지가 표시되며, 내용을 확인한
뒤에만 앱을 사용할 수 있습니다.


[ 사용 방법 ]

1. RuneTimer.exe 를 실행합니다.
2. 캡쳐 아이콘을 눌러 미니맵 영역을 지정합니다.
3. 룬이 등장하면 알림음이 울리고 룬 아이콘과 보라색 게이지가
   활성화됩니다.
4. 창모드와 전체화면을 전환했거나 미니맵 위치를 바꾼 경우에는
   캡처 영역을 다시 지정해 주세요.
5. 화면 캡처 없이 쓰고 싶다면 설정에서 수동 모드를 켜세요.


[ 포함하지 않는 기능 ]

- 키보드 입력
- 마우스 입력
- 자동 사냥
- 방향키 전환
- 스킬 사용
- 클라이언트 변조
- 패킷 조작
- 메모리 접근

이 앱은 사용자가 지정한 화면 영역만 PC 안에서 분석하며, 어떤 데이터도
외부로 전송하지 않습니다. 인터넷 연결이 필요 없습니다.


[ 비공식 보조 도구 안내 ]

룬 타이머는 메이플스토리 공식 서비스가 아니며, 넥슨 또는 게임 운영사의
공식 허가를 받은 도구가 아닙니다.

운영정책의 최종 해석과 사용 책임은 사용자 본인에게 있습니다.
최종 사용 여부는 본인 판단과 책임하에 결정해 주세요.


[ Windows 보안 경고 ]

개인이 제작한 서명되지 않은 프로그램이라 실행 시 Windows SmartScreen
경고가 표시될 수 있고, 백신이 오탐할 수 있습니다.

내려받은 파일이 원본과 같은지 확인하려면 PowerShell에서 아래를
실행해 릴리스 페이지에 적힌 SHA256 값과 비교해 주세요.

    Get-FileHash .\RuneTimer.exe -Algorithm SHA256
