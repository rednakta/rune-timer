이번 버전 변경:
- 스플래시와 첫 실행 안내창을 주 모니터 중앙에 표시
- 앱 시작 및 위젯 모드 복귀 시 창을 화면 중앙에 배치
- 해상도 또는 DPI 변경으로 잘못 저장된 창 위치를 중앙으로 복구
- 첫 실행 안내창이 응답하지 않던 문제 수정
- 서체 등록 알림으로 앱 시작이 멈추던 문제 수정

포함 기능:
- 첫 실행 사용자 책임 고지 및 동의 저장
- 설정 탭 이용 안내 다시 보기
- 미니맵 룬 감지 알림
- 룬 사라짐 시 알림음 자동 종료
- 커스텀 타이머 알림
- 타이머 일시정지/재개
- 극최소화 위젯 모드
- 수동 모드
- 수동 모드에서 홈 룬 아이콘 클릭 시 룬 게이지 재시작
- 수동 모드에서 최소화 위젯 룬 아이콘 클릭 시 룬 게이지 재시작
- 룬/타이머 알림음 개별 온오프 및 볼륨 설정
- TTS 알림음 전환

공개 제외:
- build 산출물

- 테스트 캡처 이미지
