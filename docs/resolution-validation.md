# v1.1.2 해상도 분리 검증 결과 · 2026-09-06

## 통과

- 크기 변경 시 설정 가로 중앙 유지, 공간이 충분할 때 세로 중앙 정렬.
- 스크롤바 미표시, 자식 컨트롤 위 휠 스크롤, 큰 창 전환 시 스크롤 위치 초기화.

- 통합 실행 파일의 두 UI 선택 저장 및 선택 시 실행 중 타이머 상태 보존.

- 저해상도 6개 크기(최소 242×320), 고해상도 8개 크기(최소 443×586): 타이머 카드, 게이지, 버튼 경계와 겹침 검사.
- 최소 크기의 설정 스크롤, 하단 항목 접근, 위젯 클릭 영역과 본창 복귀.
- 타이머 일시정지·재개, 알림음/TTS 설정, 볼륨 및 10분 룬 게이지 설정.
- 수동 모드 전환, 룬 주기 초기화, 설정 저장·불러오기.
- 모의 감지 결과를 입력해 룬 등장·사라짐 및 알림 요청 상태 확인.
- 저해상도 첫 실행에서 기존 설정 가져오기, 큰 창 크기 제외, 원래 설정 파일 보존.
- 기존 Git HEAD와 비교해 캡처·감지·타이머·음성·수동 모드 관련 핵심 함수 39개 동일 확인.
- 통합 PyInstaller 실행 파일 빌드, 해상도별 자산 포함, 실제 첫 실행 안내 표시 및 정상 종료.
- 최소 저해상도 화면·위젯·첫 실행 동의 화면을 이미지로 확인.
- Python 문법 검사 및 git diff --check.

## 검증 범위

UI 및 상태 전환 테스트는 임시 사용자 설정으로 수행했습니다. 오디오 출력은 테스트에서 대체했으며 실제 게임 화면을 연결한 룬 감지, 스피커 청취, 여러 모니터의 서로 다른 Windows 배율은 실환경 검증하지 않았습니다.

## 재검증

```powershell
python tools/check_resolution_ui.py --ui=low
python tools/check_resolution_ui.py --ui=high
./build_rune_timer.ps1
python tools/check_packaged_ui.py
```
