# 룬 타이머 공식 소개글

룬 타이머는 메이플스토리 플레이 중 룬 등장 상태와 사용자 지정 타이머를 확인할 수 있도록 만든 Windows용 로컬 PiP 알림 도구입니다. 사냥 화면 위에 작은 보조 창을 띄워 룬 감지 상태, 룬 게이지, 커스텀 타이머를 한눈에 확인할 수 있습니다.

## 개요

룬 타이머는 사용자가 지정한 미니맵 화면 영역을 PC 내부에서만 분석하고, 룬 아이콘이 표시될 때 알림음을 재생합니다. 게임 클라이언트의 파일, 메모리, 패킷, 키보드 입력, 마우스 입력에는 접근하지 않으며, 별도의 인터넷 연결 없이 동작합니다.

브라우저 기반 타이머 사용이 부담스러운 저사양 PC, 부트캠프 Windows, 장시간 사냥 환경을 고려해 가볍게 실행되는 독립형 앱으로 설계했습니다. 화면 캡처 기반 감지가 부담스러운 경우에는 수동 모드를 사용해 순수 타이머 기능만 사용할 수 있습니다.

## 주요 기능

- 미니맵 룬 아이콘 감지 알림
- 룬이 사라졌을 때 알림음 자동 종료
- 커스텀 타이머 생성 및 알림
- 타이머 일시정지 및 재개
- 10분 또는 15분 기준 룬 게이지 표시
- 극최소화 위젯 모드
- 룬 알림음과 타이머 알림음 개별 설정
- TTS 알림음 전환
- 캡처 없이 동작하는 수동 모드

## 동작 방식

기본 모드에서는 사용자가 직접 지정한 미니맵 영역만 로컬에서 캡처하고, 해당 화면 안에 룬 아이콘이 표시되는지 확인합니다. 룬이 감지되면 앱 화면의 룬 아이콘과 게이지가 활성화되고 알림음이 재생됩니다. 룬이 사라지면 알림음은 자동으로 종료됩니다.

수동 모드에서는 화면 캡처 스레드와 캡처 객체를 사용하지 않습니다. 앱은 순수 타이머로만 동작하며, 룬 게이지가 설정한 기준 시간에 도달하면 룬 등장 예정 알림을 재생합니다. 실제로 룬을 처리한 뒤 홈 화면 또는 위젯의 룬 아이콘을 누르면 게이지가 다시 시작됩니다.

## 설계 원칙

룬 타이머는 게임 조작이 아닌 알림 보조 기능에만 초점을 둡니다. 앱은 사용자의 입력을 대신하지 않고, 게임 클라이언트 내부 데이터에 접근하지 않으며, 네트워크를 통해 데이터를 전송하지 않습니다.

또한 장시간 실행 환경을 고려해 필요한 기능만 작은 PiP 창에 배치했습니다. 사용자는 사냥 중에도 화면을 크게 가리지 않고 룬 상태와 타이머를 확인할 수 있으며, 필요한 경우 극최소화 위젯 모드로 더 작은 화면에서 사용할 수 있습니다.

## 사용 전 안내

룬 타이머는 메이플스토리 공식 서비스가 아니며, 넥슨 또는 게임 운영사의 공식 허가를 받은 도구가 아닙니다. 이 프로그램은 사용자가 지정한 화면 영역을 분석하는 비공식 보조 도구이며, 사용 여부와 그에 따른 책임은 사용자 본인에게 있습니다.

계정 제재 리스크가 민감한 환경이거나 외부 보조 도구 사용이 부담스러운 경우에는 사용을 권장하지 않습니다. 화면 캡처 자체가 부담스러운 경우에는 설정에서 수동 모드를 켜고 순수 타이머 기능만 사용하는 방식을 권장합니다.

## 포함하지 않는 기능

- 자동 사냥
- 스킬 자동 사용
- 키보드 입력
- 마우스 입력
- 방향키 전환
- 클라이언트 변조
- 패킷 조작
- 메모리 접근
- 게임 API 사용
- 외부 서버 데이터 전송

## 권장 사용 환경

룬 타이머는 Windows 10/11 환경에서 사용하도록 제작되었습니다. 창모드와 전체화면을 전환하거나 미니맵 위치를 변경한 경우, 기존 캡처 좌표가 맞지 않을 수 있으므로 룬 영역을 다시 지정해야 합니다.

공개 배포 시에는 소스코드를 GitHub 저장소에 공개하고, 실행 파일은 GitHub Releases에 zip 파일로 첨부하는 방식을 권장합니다.
