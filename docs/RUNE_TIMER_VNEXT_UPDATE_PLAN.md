## 1. 룬 종료 후 15분 보라색 누적 바

### 목적

- 룬 쿨타임 알림용 타이머가 아니다.
- 15분이 지나도 알림음이 울리면 안 된다.
- 15분이 지나면 바가 꽉 찬 상태로 유지되어도 된다.
- 목적은 “룬이 곧 올 수 있다”는 가시성을 주는 것뿐이다.

### 시작 조건

- 룬 알림음이 울리다가 꺼지는 순간부터 시작한다.
- 정확히는 미니맵에서 룬 다이아몬드가 사라지는 순간이다.
- 이 순간을 `last_rune_cleared_at` 같은 시간값으로 저장한다.

### 진행 로직

- 룬이 사라진 뒤부터 15분 동안 보라색 경험치 바가 0% -> 100%로 누적된다.
- 진행률 공식:
  - `progress = min((현재시간 - last_rune_cleared_at) / 900초, 1.0)`
- 룬이 다시 등장하면 기존 룬 감지 상태가 우선이다.
- 룬이 다시 사라지는 순간 15분 게이지는 다시 0부터 시작한다.

### 주의

- 룬 쿨타임이 10분이 되는 이벤트도 있으므로, 15분 기준 알림음은 넣지 않는다.
- 커스텀 타이머 알림음과도 별개 로직이다.

   - 룬 감지 중에는 보라색 다이아몬드.
   - 룬 종료 후 15분 게이지는 이 영역 아래 또는 옆에 보라색 누적 바로 표시한다.

2. 오른쪽 영역: 커스텀 타이머 숫자
   - 홈 화면 숫자 폰트 기준으로 표시한다.
   - 숫자만 최대한 크게 보이게 한다.
   - 타이머 알림 루프와 동일한 남은 시간 또는 카운트 값을 보여준다.

- 15분이 지나면 꽉 찬 상태로 유지 가능하다.

## 3. 설정 탭 메뉴 업데이트

### 적용 버튼

- 현재 체크 아이콘 적용 버튼을 더 동그란 테두리 버튼으로 변경한다.
- 텍스트 없이 아이콘 중심으로 유지한다.
- 체크 아이콘은 민트/시안 계열 유지.

### 알림음 개별 온오프 토글

설정 탭에 아래 두 개 토글을 추가한다.

- 카운트 알림음
- 룬 알림음

토글 디자인:

- 민트색 ON/OFF 스타일.
- ON 상태는 민트/시안 강조.
- OFF 상태는 어두운 회색 계열.
- 문구는 최대한 짧게 유지한다.

### 알림음 소리 크기 설정

설정 탭에 개별 볼륨 게이지를 추가한다.

- 룬 알림음 볼륨
- 커스텀 타이머 알림음 볼륨

게이지 디자인:

- 시안/민트 그라데이션 바.
- 끝에 현재 볼륨 숫자 표시.
- 예: `70`
- 드래그 가능한 슬라이더 형태.

로직:

- 볼륨값은 설정 파일에 저장한다.
- 기본값은 기존 알림음과 체감이 크게 다르지 않게 100 또는 80으로 시작한다.
- ON/OFF 토글이 OFF이면 해당 알림음은 재생하지 않는다.
