# 룬 타이머 리소스 벤치마크 기록 가이드

## 목적

커뮤니티 글에 넣을 객관적인 근거를 만들기 위한 기록이다.

핵심 문장은 아래처럼 만들 수 있다.

> 제 PC 기준 3시간 사냥 중 룬 타이머 평균 CPU 0.x%, 메모리 xxMB 수준으로 유지됐고, 시작 대비 메모리 증가가 거의 없었습니다.

## 오늘 권장 방식

### 1. 룬 타이머 3시간 로그

실행 파일:

```powershell
tools\start_3h_resource_benchmark.bat
```

기록 방식:

- 10초 간격
- 3시간
- `RuneTimer`, `MapleStory`, `Browser` 그룹 기록
- CSV 저장 위치: `benchmark_logs`

결과 파일:

- `resource_log_YYYYMMDD_HHMMSS.csv`: 전체 원본 로그
- `resource_summary_YYYYMMDD_HHMMSS.csv`: 평균/최대 요약

### 2. 작업 관리자 스크린샷

스크린샷은 4장이면 충분하다.

- 시작 직후
- 1시간
- 2시간
- 3시간 종료 직전

작업 관리자에서 보이면 좋은 항목:

- 메이플스토리
- 룬 타이머
- CPU
- 메모리
- 가능하면 GPU

### 3. maple-timer 비교군

같은 조건에서 브라우저로 maple-timer를 켜고 30분~1시간만 기록해도 된다.

주의:

- 브라우저 비교는 Chrome/Edge 전체 프로세스를 합산하는 것이 공정하다.
- 가능하면 불필요한 탭은 끄고 비교한다.
- 기존 탭이 많은 상태라면 그 상태도 별도로 적어둔다.

## 해석 기준

좋은 결과:

- 룬 타이머 평균 CPU가 0.x% 수준
- 메모리가 시간에 따라 계속 우상향하지 않음
- 3시간 뒤에도 시작 대비 메모리 증가가 작음
- maple-timer 브라우저 대비 메모리 사용량이 낮음

커뮤니티에 넣기 좋은 표:

| 조건 | 평균 CPU | 최대 CPU | 평균 메모리 | 최대 메모리 |
|---|---:|---:|---:|---:|
| 메이플 + 룬 타이머 | 0.x% | x.x% | xxMB | xxMB |
| 메이플 + maple-timer 웹 | x.x% | x.x% | xxxMB | xxxMB |

## 감지 주기 기준

룬은 뜨고 몇 초 안에 사라지는 구조가 아니므로 미니맵 감지는 1초에 1~2회면 충분하다.

0.5초 이하로 너무 빠르게 돌리면 벤치마크 숫자만 나빠지고, 체감 이득은 거의 없다.
